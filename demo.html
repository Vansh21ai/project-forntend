Synaptic Weights

• Each connection has a learned weight (w)

• Weights determine signal importance

• Updated during training via backpropagation

Weighted Aggregation

• Formula: z = Σ(xᵢ × wᵢ) + bias

• Combines all weighted inputs

• Bias allows threshold shifting

Activation Threshold

• Fires if z ≥ threshold (0.5)

• Binary output: 1 (fire) or 0 (silent)

• Mimics biological neuron behavior
